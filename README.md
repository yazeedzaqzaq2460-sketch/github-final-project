# Simple Interest Calculator

A simple calculator application that computes simple interest given principal, annual rate of interest, and time period in years.

## Purpose
This tool helps users quickly calculate the interest accrued on a principal amount over a specific timeframe.

## Formula
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$
- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest
